# PDF 빈 페이지·텍스트 추출률

- 전체 PDF 파싱 문서의 선언 페이지 수와 실제 페이지 수가 일치함
- 대체 문자(`�`)는 검출되지 않음
- **제2025-79호** : OCR 재처리 후 13쪽 모두 텍스트가 추출되어 추출률 100% (v0.1의 제2025-61호 오저장 문제 해소, `needs_reparse_review=False`)
- **제2024-23호 고시** : OCR 재처리 후 13쪽 모두 텍스트가 추출되어 추출률 100% (v0.1의 228자만 추출 문제 해소, `needs_reparse_review=False`)
- 재파싱 검토 대상(`needs_reparse_review=True`) 0건
- 빈 페이지가 남아 있는 문서(본문 자체의 표지·간지 등으로 추정, 추출 실패 아님)
    - 건강기능식품 기준 및 규격 제4편 : 558쪽 중 5쪽 (추출률 99.1%)
    - 2021 부당광고 판단기준 가이드라인 : 133쪽 중 10쪽 (추출률 92.5%)
    - 온라인 자율관리 가이드라인 : 64쪽 중 5쪽 (추출률 92.2%)
    - 합본 온라인 부당광고 사례집 : 78쪽 중 3쪽 (추출률 96.2%)

> 2022년 온라인 부당광고 사례집(OCR본)은 파일명 오류로 분석 대상에서 제외된 상태 — 상단 "신규 확인 사항" 참고. 파일명 정정 후 재확인 필요.

> PDF의 경우 페이지 수 일치 여부와 텍스트 추출 성공 여부를 별도 품질 지표로 관리해야 함

## 타입 및 날짜 형식

파싱 데이터의 대부분 컬럼은 JSON 문자열로 저장되어 있음

- YYYYMMDD : 허가일, 처분일, 시작일, 종료일
- ISO datetime : 수집일, 공개일, 최종 수정일
- 숫자형 문자열 : 인허가번호, 처분번호, 분류코드
- 일반 문자열 명칭 : 주소, 기능성 내용, 원료명

> 확인된 날짜 후보 12개 컬럼은 비결측값 기준 유효 날짜 비율이 모두 100%. 단, C002와 I1250의 날짜 형식은 최대 10만 건 표본 기준

LCNS_NO, DSPSDTLS_SEQ, 각종 분류 코드, 인정번호, 제품 신고번호는 문자열로 유지해야 함

## 남은 mismatch 3건 (모두 파일명 표기 차이로, 본문·고시번호는 정상)

- `제2021-89호`(과거 고시) : 파일명이 원본보다 축약되어 원본명 연결은 끊겼으나 제목 유사도 0.82로 동일 문서
- `기능성 표시·광고 규정_제2023-20호` : 파일명이 원본(긴 고시 전문명)과 달라 원본명 불일치(유사도 0.30). 단, 내부 고시번호(`고시 제2023-20호`)·게시일(`2023-03-08`)은 이번 점검으로 정정 완료
- `광고심의 기준 및 가이드라인` : 원본 파일명 정보가 없고 내부 제목과 파일명 유사도가 낮음(0.22)

## not_applicable 3건

- `food_raw_material.jsonl`, `food_raw_material_metadata.json`, `식품관련법 위반사례_식품안전나라` : 파일 단위 제목·원본명이 없는 구조로 판정 대상 아님

## 해석 시 주의사항

- `source_name_matches_file=True`는 원본 파일명 연결만 정상이라는 뜻이며 내부 제목·고시 번호까지 정상이라는 의미는 아님
- 제목 유사도만으로 법률·시행령·시행규칙 차이를 판별하기 어려움
- `match_or_review` 상태에도 실제 메타데이터 오류가 포함될 수 있어 고시 번호, 문서 유형, 날짜를 우선 확인해야 함
- JSONL, 최상위 배열 등 파일 단위 메타데이터가 없는 구조는 `metadata_missing_or_not_applicable`로 구분됨

> 본문 추출이 정상인 문서는 전체 재파싱보다 메타데이터만 다시 생성하는 방식이 효율적

# 구조화 전 후속 조치

1. 2022년 온라인 부당광고 사례집 OCR 파일명(`...)json` → `....json`)을 정정해 분석·구조화 대상에 포함
2. `기능성 표시·광고 규정_제2023-20호` 등 파일명과 원본명이 다른 3건은 파일명 또는 원본 경로 메타데이터를 정렬
3. I1250-C002 미일치 175건(I1250 83 / C002 92)의 원인 확인
4. 인정번호와 `DSPSDTLS_SEQ` 중복 레코드의 동일·이력·충돌 여부 확인
5. 100% 결측 컬럼(RAWMTRL_STATS_CD_NM, PRSDNT_NM, TELNO, CHILD_CRTFC_YN 등)은 원본 미제공 여부를 확인한 후 제거 또는 nullable 유지 여부 결정
6. 식별자와 분류코드는 숫자형으로 변환하지 않고 문자열로 유지
7. 법령 객체는 조/항/호 단위의 별도 중첩 구조 EDA 수행
