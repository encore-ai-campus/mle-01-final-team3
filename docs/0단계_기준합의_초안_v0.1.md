# 0단계 합의 내용

2026-11-26 기준

## 인증

- 세션 쿠키 `adguard_session` 방식, 세션은 DB `sessions` 테이블에 저장 (토큰은 SHA-256 값만 저장)
- 세션 만료: 로그인 시점부터 고정 10시간 (요청해도 연장하지 않음)
- 로그아웃하면 그 세션 삭제, 비활성화·역할 변경·삭제 시 그 사용자 세션 전부 삭제
- 세션이 없거나 만료되면 `401 UNAUTHENTICATED`

## 계정

- 첫 ADMIN 발급: 운영(배포)은 CLI 명령, 개발은 시드 스크립트(ADMIN·MARKETING·LEGAL 테스트 계정)
- 임시 비밀번호 상태여도 다른 기능을 막지 않고, 비밀번호를 바꿀 때까지 계속 안내

## ID 규칙

- 개발 중: `접두어_순번` (예: `usr_001`, `revw_001`, `run_001`)
- 배포 전: DB 초기화 후 `접두어_랜덤`으로 전환 (예: `usr_reil4lk`)

## 진행 상태

- v5.0은 폴링 기준

## 담당

- 가현: 공통 스키마·마이그레이션 전체, 인증, 사용자 관리, 중복 요청 방지 공통 처리, 법무 검토 요청, 알림
- 기표: 검토 요청, 실행, 보고서, Agent 연동
