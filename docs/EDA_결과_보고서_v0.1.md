## 파일 구조 검증

`document + records`와 `document + pages` 구조의 파일은 대부분 내부 선언 건수와 실제 건수가 일치함

- 개별인정형 정보 : 457건 일치
- PDF 파싱 문서 : 대부분 선언 페이지 수와 실제 페이지 수 일치

`root_array`, `jsonl`, 법령 객체에는 자체 `record_count`가 없으므로 `declared_count=NaN`인 것은 오류가 아님

법령 JSON의 `actual_record_or_page_count=1`, `column_count=1`은 법령이 한 건이라는 뜻이 아니라 최상위 객체가 하나라는 의미(조/항/호 단위 분석은 별도의 중첩 구조 프로파일링이 필요)

# PDF 빈 페이지·텍스트 추출률

- 전체 PDF 파싱 문서의 선언 페이지 수와 실제 페이지 수가 일치함
- 대체 문자(`�`)는 검출되지 않음
- 2022년 온라인 부당광고 사례집은 84쪽 중 83쪽의 `text`가 비어 있어 결측률이 98.8%(본문 추출 실패)
- 2021 부당광고 판단기준 가이드라인에 빈 페이지가 10쪽임
- 온라인 자율관리 가이드라인의 빈 페이지 5쪽
- 합본 온라인 부당광고 사례집 : 빈페이지 3쪽
- 건강기능식품 기준 및 규격 제4편 : 빈페이지 5쪽
- 제2024-23호 고시 : 13쪽 중 12쪽에 값은 있으나 총 228자만 추출되어 재파싱 검토 필요

> PDF의 경우 페이지 수 일치 여부와 텍스트 추출 성공 여부를 별도 품질 지표로 관리해야 함

> 제2025-79호는 27쪽 모두 텍스트가 있어 추출 지표상 정상으로 보이지만 실제 내용은 제2025-61호이므로 내용 일치 검증이 별도로 필요함

## 타입 및 날짜 형식

파싱 데이터의 대부분 컬럼은 JSON 문자열로 저장되어 있음

- YYYYMMDD : 허가일, 처분일, 시작일, 종료일
- ISO datetime : 수집일, 공개일, 최종 수정일
- 숫자형 문자열 : 인허가번호, 처분번호, 분류코드
- 일반 문자열 명칭 : 주소, 기능성 내용, 원료명

> 확인된 날짜 후보 12개 컬럼은 비결측값 기준 유효 날짜 비율이 모두 100%. 단, C002와 I1250의 날짜 형식은 최대 10만 건 표본 기준

LCNS_NO, DSPSDTLS_SEQ, 각종 분류 코드, 인정번호, 제품 신고번호는 문자열로 유지해야 함

## 키 중복 및 조인 가능성

- `DSPSDTLS_SEQ`는 5,060건 모두 값이 존재하지만 고유값은 5,059개이므로 중복 키가 1개 존재함
    - 중복 레코드가 완전히 동일한지, 수정 이력인지, 내용 충돌인지 확인해야 함
- `LCNS_NO`는 5,060건 중 고유값이 5,031개이지만 업체 하나에 여러 처분이 연결될 수 있으므로 기본키가 아닌 외래키 후보로 봐야 함
- 건강기능식품 개별인정형 정보의 인정번호는 457건 중 455개가 고유함
    - `제2013-5호`, `제2021-5호`가 각각 2건
- 기능성 원료 인정번호는 778개 비결측값 중 774개가 고유함
    - 중복을 바로 삭제하지 않고 원료명·업체·허가일 등 다른 컬럼을 비교해야 함

# 파일명과 내부 메타데이터 일치 여부

## 주요 결과

- PDF 파서의 고정 메타데이터가 여러 문서에 반복 저장됨
    - 내부 제목 : 건강기능식품의 표시기준 고시전문
    - 고시 번호 : 제2025-61호
    - 게시일 : 2025-08-29
- CSV 파서의 고정 제목인 건강기능식품 개별인정형 정보가 I0030, C002, I1250, 영양DB, 품목분류 등에 잘못 저장됨
- 제2025-79호 파일은 파일명과 원본 파일명·내부 제목·고시 번호가 모두 불일치함
- 건강기능식품에 관한 법률 시행규칙 파일의 내부 제목이 시행령으로 저장됨
- 친환경농어업 관련 법률 파일의 내부 제목이 농림축산식품부 소관 시행규칙으로 저장됨

## 해석 시 주의사항

- `source_name_matches_file=True`는 원본 파일명 연결만 정상이라는 뜻이며 내부 제목·고시 번호까지 정상이라는 의미는 아님
- 제목 유사도만으로 법률·시행령·시행규칙 차이를 판별하기 어려움
- `match_or_review` 상태에도 실제 메타데이터 오류가 포함될 수 있어 고시 번호, 문서 유형, 날짜를 우선 확인해야 함
- JSONL, 최상위 배열 등 파일 단위 메타데이터가 없는 구조는 `metadata_missing_expected`로 구분하는 것이 적절함

> 본문 추출이 정상인 문서는 전체 재파싱보다 메타데이터만 다시 생성하는 방식이 효율적

# 구조화 전 후속 조치

1. 제2025-79호, 2022년 온라인 부당광고 사례집, 제2024-23호를 우선 재파싱
2. 본문은 정상이나 메타데이터가 잘못된 PDF는 메타데이터만 다시 생성
3. CSV 파서의 고정 제목을 제거하고 데이터셋별 제목 적용
4. I1250-C002 미일치 175건의 원인 확인
5. 인정번호와 `DSPSDTLS_SEQ` 중복 레코드의 동일·이력·충돌 여부 확인
6. 100% 결측 컬럼은 원본 미제공 여부를 확인한 후 제거 또는 nullable 유지 여부 결정
7. 식별자와 분류코드는 숫자형으로 변환하지 않고 문자열로 유지
8. 법령 객체는 조/항/호 단위의 별도 중첩 구조 EDA 수행
